# N-cleo3Pro-Curso-BFD-
Projeto de desenvolvimento para empresa Núcleo3Pro, focado em desenvolver um ecossistema composto por um chatbot integrado à API do WhatsApp (capaz de guiar o usuário desde a dúvida inicial até o pagamento) e um Painel Administrativo Web para gerenciamento de cursos, editais, leads e relatórios de vendas.
