# Núcleo3Pro-Curso-BFD

Projeto de desenvolvimento para a empresa **Núcleo3Pro**, focado em desenvolver um ecossistema composto por:
1. **Chatbot integrado à API do WhatsApp:** Capaz de guiar o usuário desde a dúvida inicial sobre editais e cursos até o fechamento e pagamento.
2. **Painel Administrativo Web:** Gerenciamento centralizado de cursos, editais, leads captados, atendimento humano e relatórios de vendas.

## 🛠️ Stack Tecnológico

- **Frontend:** React 19, Vite 8, Tailwind CSS v4
- **UI & Componentes:** Shadcn/UI, Lucide React, Phosphor Icons
- **Qualidade de Código:** Oxlint

---

## 🚀 Como Rodar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar servidor local
npm run dev

# Executar checagem de lint
npm run lint

# Gerar build de produção
npm run build
```
